Entity store using Azure Blob Storage.

NOTE: not for arbitrary binaries, just for Seneca data entities.

## Install

```sh
npm install @seneca/azureblob-store
```

## Quick Example

```js
require('seneca')()
  .use('@seneca/azureblob-store')
```
